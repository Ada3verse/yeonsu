“세련된 웹사이트 만들어 줘. 카드도 예쁘게 하고 스크롤 효과도 넣고 설정 화면도 멋지게.”

용어로 쓴 요청 예시
  • 첫 화면은 Hero Section
  • 핵심 기능은 Bento Grid
  • 상단 메뉴는 Sticky Header
  • 설정은 오른쪽 Drawer · ESC로 닫기
  • 카드에는 가벼운 Hover와 Scroll Reveal
  • 카드는 0.1초 간격 Stagger Animation
  • 전체는 Responsive Layout · 모바일 1열

직접 해 보기

    

      
1
요청 문장 복사
용어 슬라이드의 📋 복사 버튼을 누르거나, 아래 시작 문장을 복사해요.

      
2
AI에 붙여 넣기
ChatGPT나 Claude 채팅창에 붙여 넣고 보내요. 끝에 “HTML 파일 하나로 만들어 줘”를 붙이면 좋아요.

      
3
화면으로 확인 → 말로 고치기
마음에 안 들면 용어를 써서 다시 말해요. “카드에 호버 이펙트를 넣어 줘”
내 수업 자료는 패들렛의 프롬프트 틀로 만들어요.

    

    
시작 문장
“1학년 3반 소개 웹페이지를 HTML 파일 하나로 만들어 줘. 첫 화면은 히어로 섹션과 CTA 버튼, 학급 규칙 3가지는 카드 레이아웃, 자주 묻는 질문은 아코디언으로 해 줘.”

    

      
ChatGPT에서 보기
요청 끝에 “캔버스에서 보여 줘”를 붙이면 오른쪽 캔버스에 코드가 열려요. 위쪽 미리 보기를 누르면 화면으로 보여요.

      
Claude에서 보기
답변 옆 창(아티팩트)에 화면이 바로 열려요. 안 열리면 설정 → 기능에서 코드 실행·파일 생성 옵션을 켜 주세요.

      
어떤 AI든 되는 방법
“.html 파일로 내려받게 해 줘” → 내려받아 더블클릭. 파일을 못 받으면 코드를 메모장에 붙여 넣고 우리반.html · 파일 형식 모든 파일 · 인코딩 UTF-8로 저장해요.
